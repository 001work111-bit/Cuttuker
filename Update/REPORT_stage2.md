## 8. Не проверено и ограничения

1. Квадратный формат (1:1) и 4:3: нет шаблонов для прогона.
2. Дубликат блока на таймлайне: в интерфейсе PMS такой команды нет. Проверена только копия данных (`deepClone`). Дубликат шаблона в `user.js` не касается слотов блока.
3. Фильтр тегов: в библиотеке нет тегов, проверен только пустой список.
4. Слоты `<img>`: масштаб и позиция работают только для `background-image`.
5. Монитор при `blur` вызывает `persistMountedTemplateHtml` и переписывает HTML блока (служебные `data-ms-node-id`, inline-стили `rc-stage`, `<style>`). Существующая логика, я её не менял. Содержимое блока сохраняется, но побайтно совпадает с результатом расчёта не всегда.
6. Метод карточки сменился с `smart` на `split` во время работы со слотами. Причина не выяснена (возможно, перерисовка инспектора с методом по умолчанию из метаданных шаблона). Нужна отдельная проверка.
7. Статусы `warning`/`failed` и обязательные проверки капсул в Electron не воспроизводились; подтверждение `sourceFormats` не реализовано.
8. Вручные сценарии (внешний вид, поведение на реальных проектах) не выполнялись.
9. Из 22 целевых проверок ТЗ отдельно по номерам я не сверял: перечисленные выше тесты покрывают большую часть блоков (галерея, адаптация, слоты, save/reopen), но прямой сопоставки с номерами ТЗ в отчёте нет. Её надо сделать по самому ТЗ.

# Этап 1a (Sandbox): единый экспорт librarymotion.js

## Что изменено
- `motion-converter.js`: новая функция `buildUnifiedLibraryJs(templates)` — один выпуск `librarymotion.js`
  с Recompose-метаданными (`RC_pickMeta`) и контрактом `motion-studio-template-v1` (entities, motion, aspect, canvas).
  - Точные дубликаты (tpl + нормализованный HTML + aspect) дают один шаблон; `styleSystems` и `groups` объединяются.
  - Непустые поля первого экземпляра не затираются; расхождения попадают в предупреждения отчёта.
  - Формат определяется автоматически (aspect каждого шаблона).
  - Старый отдельный экспорт Motion Studio (диалог, `buildMotionLibraryJs`) удалён; кнопка скрыта и больше не обрабатывается.
  - Исправлена потеря `favorite` в старом Motion-экспорте (поле не переносилось).
- `Sandbox_Content.html`:
  - Окно «⬇ Экспорт»: «Выделенные», «Вся библиотека», «Стили» (чекбоксы, один или несколько). Назначения: PMS (`librarymotion.js`) и JSON для AI.
  - Блок «Формат» и пункт Motion Studio убраны из окна. Архив в окно не входит (кнопка «Сохранить архив» в тулбаре).
  - `buildLibraryJs()` делегирует в `SB_motionExporter.buildUnifiedLibraryJs` (одна реализация).
- Архив (`btnArchiveSave` / загрузка): добавлены поля `conv` (связи конвертаций) и `imgAssign` (назначения изображений по слотам).
  Раньше они хранились только в localStorage и при переносе архива терялись. Старые архивы без этих полей загружаются.
- Кнопка «Экспорт» не открывает архив и не дублирует Motion Studio.

## Проверки
- Автотест (headless Chromium): 37/37. Сценарии: состав окна, файл `librarymotion.js`, дубликаты, стили, выделение,
  блокировка без стилей, JSON для AI, архив (round trip), архив без новых полей, отсутствие ошибок JS.

## Ограничения
- В Sandbox принадлежность шаблона к стилю по-прежнему одна (`styleSystem`). Список `styleSystems` в экспорте
  пока содержит только её; множественную принадлежность создаёт этап 2a (PMS) и решение по «копии в стиль».
- Дубликаты объединяются только при одинаковом `tpl`. Копии с другим `tpl` и тем же HTML (создаются «копией в стиль») пока экспортируются отдельно — см. вопрос.
- `sandbox_ui` (настройки интерфейса) в архив не входит — это не данные программы.
- `file://`-пути назначений изображений действуют только на той же машине.

Вставить шаблон (JSON от нейросети)

Вставь JSON-массив шаблонов (или один объект). Формат:
[{"tpl":"...","group":"...","label":"...","code":"...","icon":"◧","html":"<section>...</section>"}]
Тип (auto/static) определится сам по наличию data-sb-repeat. HTML — строка.

Для новых AI-шаблонов выбери целевой формат. Sandbox физически закрепит root frame; старые шаблоны по умолчанию не меняются.
Universal Frame Contract
Format = W:H. 16:9, 9:16 и будущие 4:5 / 5:6 используют один и тот же механизм. Финальное разрешение не фиксируется в дизайне.

Собрать пак-файлы

Выбранные шаблоны (галочки слева) будут собраны в пак-файлы по своим группам. Если выбрано ничего — экспортируется вся библиотека. Каждый файл кладётся в templates/ рядом с Site Builder.

⧉ JSON выбранных шаблонов

Берём только шаблоны, отмеченные в библиотеке. Конвертированные версии помечены отдельно и по умолчанию не включаются — их можно включить вручную. Для каждого включённого шаблона добавляется временный _realGeometry с фактическим runtime-размером и ratio.
Чистый JSON — точно такой же объект, как «Копировать JSON» в инспекторе.

⌨ Горячие клавиши

Кликни по комбинации и нажми нужные клавиши. Esc — отмена записи.

⚙ Настройки стилей

Кликни по квадрату — сменить цвет. Имя правится в поле. «Базовый» удалить нельзя.

# Flat image mode notes

## UX
- Загрузи файл через `+ Плоское`.
- В селекторе `Источник` выбери `Плоское изображение`.
- Колесо мыши — zoom.
- ЛКМ drag — pan.
- `Capture` делает кадр из текущего окна проекта в выбранном aspect.
- В инспекторе картинки есть кнопка `Открыть в flat`.

## Реализация
- flat viewer использует ту же проектную рамку aspect ratio, что и панорама;
- capture идёт через отдельную функцию `captureFlatImageFrameSyncBase()`;
- overlays Draw / Titles остаются общими, потому что живут поверх общего source-box.

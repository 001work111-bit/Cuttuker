Recompose Studio — 16:9 → 9:16

Запуск: откройте recompose-studio-9x16.html в Chrome или Edge.

Встроена тестовая библиотека из 11 шаблонов To_169.js. Чтобы проверять другие шаблоны, нажмите «Добавить JS» или «Загрузить папку» и выберите библиотеку/папку с .js файлами.

Программа работает локально в браузере и не меняет исходные библиотеки. Слева показывается исходный шаблон с его естественной высотой, справа — вертикальный кадр 9:16 (900 × 1600). Доступны четыре метода: smart, compact, split и fit.

Ограничения: это лабораторный прототип. Шаблоны со сложной динамической генерацией HTML через ${...} не поддерживаются текущим CSP-safe парсером; в шаблонах с пустыми data-sb-media отображаются исходные медиа-заполнители, так как сами картинки в JS библиотеке могут отсутствовать. Проверяйте композицию визуально перед использованием.
